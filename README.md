# libary_manegement.github.io
libary manegement system 

Sistema de gerenciamento de biblioteca onde o usuario fornece seus dados (cpf, numero e endereço) e lhe é permitido fazer consultas e substabelecer até 10 livros por mês, caso o cliente se coloque na osição de inadimplente, por motivo de mal uso do livro ou atraso na devolução a quantidade será reduzida para 2 livros no mes. 
Funcionarios sao divididos entre gerente e recepcionista. possui acesso total ao sistema, o gerente é responsável por administrar os cadastros dos clientes, recepcionistas e todo o acervo de livros. o recepcionista tem a função de registrar os clientes e verificar a disponibilidade dos livros no estoque, bem como a quantidade restante e a permissao de cobrar os clientes que estão em atraso na devolução. 

Sobre o atraso: O recepcionista fica encarregado de registrar o atraso/avaria, gerar a multa correspondente e realizar o recebimento do valor devido para que o cliente possa regularizar sua situação.


Todo cliente tem a janela de 01 mes, contados a partir da data de em que o cliente retirou os livros, para devolução. esse prazo pode ser prorrogado por mais 01 mes nao podendo superar o prazo maximo de 02 meses.
